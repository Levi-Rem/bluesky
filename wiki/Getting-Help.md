If you would like to get information about a specific command or just need help, type in the command line

    HELP 

![help_command](images/bluesky_help_command.png)

This will provide you with different options how you could get help:

![help_output](images/bluesky_help_output.png)


    HELP PDF

allows you to access a PDF file containing all BlueSky commands, their description, and required and optional arguments.

    HELP cmd

provides with the description of a command and its syntax. For instance,

    HELP ADDWPT

provides the following information:

> ADDWPT acid,(wpname/lat,lon/FLYBY/FLYOVER/ TAKEOFF,APT/RWY),[alt,spd,afterwp]
>
> Add a waypoint to route of aircraft (FMS)

The first line indicates how you should type in the command. The second line gives the description of the command. 

    DOC cmd

allows to access the command documentation (if available).

For instance, 

    DOC ADDWPT     

opens the following window:

![DOC_addwpt](doc_addwpt.png)
