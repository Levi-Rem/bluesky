If you use QtGl, BlueSky will start and look similar to the image above. The BlueSky interface consists of several elements: 
### Main mapview (yellow)
This section contains the main topdown overview of the traffic situation. Any relevant aircraft information may be displayed here, as well as navigation waypoints and other geometrical elements of interest.
### Command line (red)
This is where you can enter commands for BlueSky.
### Text Output (cyan)
This screen contains text output from the commands given, similar to the command window on your computer operating system.
### Simulation Controls (blue)
These buttons give you quick access to some commands. This consists of three tabs:
* M contains the time control commands and scenario selection
* D contains display commands
* C has space for user-defined custom commands
### Simulation State (green)
The states of 8 general simulation parameters are displayed here. On the left is the current simulation time: t.
### Camera Controls (magenta) 
Six buttons can be used to have the camera in the main mapview move west, east, north, south or to zoom in or out. You can try the use of these buttons now.
