# 首版飞行仿真闭环验收问题与用例

## 1. 使用方法

验收不是检查“代码是否存在”，而是从系统外部回答下列问题。每个问题只能记录“通过”“不通过”或“阻塞”，并附可重复的命令、HTTP 响应、测试报告或页面截图。任何必验项不通过，都不能称为首版闭环完成。

## 3. 自动化验收用例

### AT-01 启动快照与复位

```gherkin
Given 数据库中存在上次运行的航空器和指令
When 平台重新启动并完成 Flyway 与启动复位
Then GET /api/v1/workstation/bootstrap 返回 READY
And simulationTimeSeconds 为 0
And aircraft 为空
And 默认终端为 PP-DEFAULT
```

### AT-02 训练组生命周期

```gherkin
Given 默认训练组为 READY 且 Adapter 可用
When 调用 start、pause、resume
Then 状态依次为 RUNNING、PAUSED、RUNNING
And Adapter 对应操作各执行一次
And 每次变化均通过 SSE 发布
```

### AT-03 合法建机

```gherkin
Given BlueSky 能识别输入机型、机场和航路点
When 创建 CCA3582 且二次代码为 1234
Then Adapter 中存在 CCA3582
And 平台 aircraft API 返回该航空器
And assignedTerminalId 为 PP-DEFAULT
And SSE 收到 aircraft-upserted
```

### AT-04 建机原子失败

```gherkin
Given 当前不存在 BAD001
When Adapter 拒绝 BAD001 的未知航路点
Then 创建 API 返回稳定错误码
And 平台数据库没有 BAD001
And BlueSky 中没有 BAD001
```

### AT-05 指令队列

```gherkin
Given 航空器正在执行 ALT 12000
And 横向通道正在执行 HDG 090
And 横向通道队尾存在 HDG 270
When Enter 提交 DCT CEN
Then DCT CEN 位于 HDG 090 之后且 HDG 270 之前
When Shift+Enter 提交 DCT CEN
Then DCT CEN 位于队尾
When Ctrl+Enter 提交 HDG 180
Then 当前横向指令和原横向待执行队列被取消且 HDG 180 立即进入执行
And ALT 12000 所在垂直通道不受影响
```

### AT-06 RTE 原子替换

```gherkin
Given 未飞航路为 CEN CON GYA ZBAA
When 提交 RTE CEN CON LMN ZBAA
Then 未飞航路正好为 CEN CON LMN ZBAA
When 提交包含未知点的 RTE
Then 指令失败且上一条未飞航路保持不变
```

### AT-07 SSE 重连

```gherkin
Given 页面已收到 sequence 20
When SSE 网络连接中断且期间状态继续变化
And 页面重新连接
Then 首个 snapshot 反映服务器当前状态
And 后续只接受更大的 sequence
```

### AT-08 真实引擎运动

```gherkin
Given 真实 BlueSky 已启动且训练组 RUNNING
And 已创建一架高度 9000 ft、航向 360 的航空器
When 提交 HDG 090
Then 连续状态中实际航向发生变化
And 最终进入 90±2 度
And 指令状态变为 COMPLETED
```

### AT-09 Adapter 重启与迟到帧

```gherkin
Given Java 已接收 Adapter A 的 sequence 99
When Adapter B 启动并发送 sequence 1
And Adapter A 的 sequence 100 迟到
Then Java 接受 Adapter B 的新序列
And 丢弃已经被替换的 Adapter A 迟到帧
```

### AT-10 DCT/RTE 单调回执

```gherkin
Given DCT 目标点刚成为活动航路点但尚未通过
When Adapter 回传相同 commandId 且 passed=false
Then DCT 保持 EXECUTING
When Adapter 回传相同 commandId 且 passed=true
Then DCT 进入 COMPLETED
And RTE 只在相同 commandId 的 activated=true 回执后完成
```

## 4. 人工界面验收脚本

1. 执行一键启动，确认只打开一个工作台页面且无登录页。
2. 检查顶部悬浮条只有合并的运行/暂停按钮、仿真时间、`0/0` 或本席/全组数量、状态灯；悬停状态灯显示说明。
3. 隐藏并恢复顶部、左侧区域，确认态势图仍占满窗口。
4. 创建两架航空器，检查左栏两行信息、标牌三行信息和 `2/2`。
5. 在空白处按住左键拖动、滚轮缩放；单击航空器后只选中，不自动居中。
6. 依次用三种快捷键提交指令，检查紧凑队列的顺序和底色，不应出现大段快捷键或状态说明。
7. 执行 HDG、ALT、SPD/MACH、DCT、RTE，观察实际标牌和航迹变化。
8. 暂停 10 秒，确认仿真时间和航空器位置停止；继续后恢复。
9. 断开并恢复 SSE，确认页面最终状态与服务端一致。
10. 断开外网，刷新页面并重复拖动/缩放，确认没有在线地图依赖。
