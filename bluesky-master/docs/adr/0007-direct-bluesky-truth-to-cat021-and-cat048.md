# 直接将 BlueSky 真值编码为 CAT021 和 CAT048

本期航迹报文输出直接把 BlueSky 航空器真值和训练平台补充字段映射为 ASTERIX CAT021 与 CAT048，不建设 ADS-B 链路、雷达站扫描、覆盖、探测概率、量测误差、虚警、单雷达航迹形成或多源融合模型。CAT062 本期不编码、不发送，只在统一航迹报文输出框架中保留类别适配器接口和配置扩展点。该选择以较低成本满足外部系统的协议接入与数据联调需求，但不提供监视传感器真实性。

目标接收系统尚未提供 ICD，因此暂以 CAT021 Edition 2.7 和 CAT048 Edition 1.32 作为设计与本地联调基线。Edition、UAP、字段映射、SAC/SIC、发送周期和 UDP 单播/组播参数必须版本化配置；收到 ICD 后重新评审并生成目标配置，临时基线不作为最终接口验收依据。

## 后果

- CAT021 和 CAT048 共享标准化航空器状态快照，但分别使用独立类别映射器、Edition/UAP 配置、校验器和发送通道
- CAT048 的位置、速度和航迹等字段来自 BlueSky 真值，不得宣称为雷达量测，也不得用于雷达探测或误差精度验收
- 数据源标识、目标地址、二次代码、FSA 和质量字段等 BlueSky 缺失数据由训练平台业务对象或输出配置补充；十二位 Track Number 不进入 BlueSky 航空器实体，由 ASTERIX 输出层按“训练组 + Category + SAC/SIC + 航空器”维护稳定映射
- Track Number 使用 `0001–4095`，待出现目标不分配；CAT021、CAT048 及不同 CAT048 逻辑雷达站分别分配，同一数据源的多个网络端点共享号码。目标暂时离开 CAT048 范围仍保留号码，删除后也在训练组结束前禁止分配给其他目标
- CAT048 首份范围内普通报告直接建立活动航迹；首次离开范围、删除航空器或正常结束训练组时，对仍活动的航迹发送一次 `I048/170 TRE=1` 终止报告。重新进入范围后使用保留的原 Track Number 恢复普通报告；暂停不终止航迹，CAT021 不模拟终止报文
- CAT062 适配器遵循与 CAT021/CAT048 相同的输入和生命周期接口，但本期实现返回“类别未启用/未实现”，不得生成伪 CAT062 报文
- 未来增加雷达或融合模型时应在标准化状态快照之前插入监视处理组件，不改变工作台、训练编排或 BlueSky 内核接口
- CAT048 配置一个或多个逻辑雷达站，使用站点经纬度和高度把 BlueSky WGS-84 真值换算为相对距离与方位，并按最大输出范围过滤；不加入扫描、误差、漏检或延迟。雷达站的 SAC/SIC、位置、范围及练习启用关系由数据准备与练习计划模块管理
- CAT021 和 CAT048 默认均以五秒为发送周期，周期为系统配置且可以按 Category 或通道覆盖。调度依据系统真实时间，报文时间使用当前仿真时间；本期工作台不提供快进或倍速控制。训练暂停期间停止发送，恢复后从新周期继续且不补发暂停数据
- 同一 Category、SAC/SIC 和目标端点的航空器记录批量编码；每个 UDP 数据报默认只承载一个完整 ASTERIX Data Block。默认 UDP 应用载荷上限为 1400 字节，超限时按完整航空器记录边界拆包，单条记录不得跨报文。单架编码失败仅跳过该记录、累计错误并告警，不能阻断其他航空器发送，也不保存失败字节
- Category、SAC、SIC、目标 IP 和目标端口共同定义一个 ASTERIX 输出流；同一输出流同一时刻只能由一个训练组独占启用。通道停止或训练组结束时释放占用，冲突只阻止通道开启而不阻止训练组运行；Category 或 SAC/SIC 不同的流可以共享端点
- CAT048 航迹活动/终止状态按输出流分别维护，同一数据源复制到不同端点时共享 Track Number 但不共享接收端生命周期。手动停止 CAT048 通道时即使训练暂停也先尝试终止该流全部活动航迹，再无条件停止并释放占用；CAT021 直接停止，重新开启时沿用训练组内保留号码
