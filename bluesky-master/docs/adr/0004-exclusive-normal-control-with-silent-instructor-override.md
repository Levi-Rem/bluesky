# 整机常规控制互斥并允许教员隐式越权

> 本 ADR 已被 [ADR-0009](./0009-visible-instructor-override-and-pilot-group-control.md) 替代。以下内容只保留决策演进背景，不再作为当前设计或验收依据。

每架航空器采用整机级互斥常规控制状态，只能由智能机长系统或模拟飞行员之一控制；模拟飞行员有权双向切换这两种状态。教员不参与常规控制权竞争，而通过独立的隐式越权通道直接下达指令：越权不改变当前常规控制状态，也不向智能机长系统或模拟飞行员工作台显示教员介入，但训练平台必须在受限审计记录中保留全部过程。该模型避免两个常规控制方同时驱动同一航空器，同时满足教员无感干预训练进程的要求。

教员超控是可以被后续合法指令覆盖的飞行控制行为，不形成默认持续锁定。例如教员使航空器突然左转后，当前常规控制方可以再用新的航向指令直接覆盖该目标。新指令与正在执行指令的关系必须显式采用“当前完成后执行”或“立即覆盖执行”之一；这属于执行调度，不改变常规控制权。

## 后果

- 航空器业务状态必须保存当前常规控制模式及其变更时间、变更人和原因
- 非当前常规控制方提交的指令不得进入 BlueSky，必须在指令网关处拒绝
- 模拟飞行员模式切换是整机级原子操作，不能出现部分控制量仍归另一方的中间状态
- 模式切换成功后立即拒绝原控制方的新指令；原控制方各通道已经开始执行的指令保留，仍在等待队列中的指令全部取消并记录“控制模式已切换”
- 新控制方可以立即按 ADR-0005 的分通道调度规则提交覆盖或排队指令；如果没有新指令，航空器继续执行切换前已经开始的飞行目标
- 新建航空器默认采用模拟飞行员控制模式，练习计划可显式指定初始模式；没有模拟飞行员分配时只产生告警，不自动切换到智能机长控制
- 教员界面可查看真实控制模式和越权执行结果；常规控制端收到的状态和事件必须按可见性规则过滤
- 内部审计数据与对常规控制方公开的数据必须分层，避免通过错误信息或事件订阅泄露教员介入
- 被立即覆盖的指令必须保留“已被覆盖”状态及替代指令关联，不能伪装成正常完成
- 等待执行的指令必须具有可追踪的前置关系、完成判据和异常处置规则
