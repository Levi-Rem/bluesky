# 每个训练组使用独立 BlueSky 实例

每个运行中的训练组绑定一个独立 BlueSky 进程或容器和独立仿真时钟；一个实例只服务一个训练组，不使用 BlueSky Traffic Group 或同一实例内的航空器集合模拟训练隔离。训练组编排器负责实例创建、健康监控、运行控制、异常告警和训练结束后的释放，平台共享服务则负责终端配置、基础数据、练习计划、记录归档和评估。

## 后果

- 每组航空器、场景、天气、指令通道、席位分配、通信资源、事件时间线和记录必须以训练组 ID 隔离
- 开始、暂停和结束只能作用于明确目标训练组；本期工作台不提供快进或倍速控制
- 单个实例异常不得影响其他训练组；平台独立报告每组健康状态，本期不设计自动恢复训练流程
- 训练开始前由编排器分配端口、进程或容器标识、工作目录和输出目录，训练归档后再安全释放资源
- 业务服务不得把 BlueSky node ID 当作稳定训练组标识；实例重建后训练组 ID 保持不变
- 目标部署可以从本机多进程演进为多主机或容器部署，而不改变训练组和业务接口语义
