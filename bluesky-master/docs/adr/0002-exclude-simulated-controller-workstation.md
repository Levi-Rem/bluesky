# 不建设模拟管制员席位

目标系统不建设规范中的模拟管制员席位，也不将 BlueSky 原有 Qt 态势界面改造成正式管制工作台。正式席位和工作区包括教员工作台、模拟飞行员工作台以及数据准备与分析工作台；管制指令通过项目外部链路或其他后续确认的来源进入训练流程。该范围选择减少重复建设管制工作环境，并使本系统聚焦于飞行活动仿真、模拟飞行员操作、训练组织、通信记录和分析评估。

## 后果

- 规范 2.4“模拟管制”及其他仅服务于模拟管制员席位的条款在本项目需求追踪矩阵中标记为“范围外”，不能标记为“已满足”
- 系统仍需维护航空器控制权、指令来源和操作审计，以支持模拟飞行员安全执行指令
- 必须另行明确管制指令的产生方、输入渠道、确认方式和链路失效处置
- BlueSky Qt 界面只作为开发诊断工具，不计入正式交付席位
