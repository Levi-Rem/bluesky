# 系统不设置登录并依赖席位与网络边界

教员、模拟飞行员、数据准备与分析工作台、智能机长以及 BlueSky Adapter 均不提供账号、密码、Token、SSO 或客户端凭证。工作台功能通过部署或启动时确定的席位类型及训练组上下文隔离，Java 平台仍在服务端校验席位类型允许调用的接口，但这种校验不构成自然人身份认证。

## 后果

- 训练记录只能可信记录席位类型、终端 ID、训练组、调用来源和操作内容，不能证明具体自然人身份
- 所有 REST、SSE、ZeroMQ、UDP 和管理接口只能部署在隔离受控网络，并通过防火墙、端口绑定和主机访问控制限制来源，禁止直接暴露到互联网或不可信办公网
- 若后续部署环境无法提供可信网络隔离，必须重新评审并增加认证机制，而不能继续假设接口调用者可信
- 前端隐藏按钮不能替代服务端功能隔离；Java 平台必须拒绝席位类型无权执行的接口调用
- 无登录显著降低人员追责能力，需求追踪矩阵中涉及用户登录、人员身份审计和基于账号权限的规范条款应标记为本期范围外
- 教员、模拟飞行员、数据准备与分析工作台由同一 Vue 工程提供三个独立入口；启动配置固定席位类型、终端 ID、平台地址和训练组选择范围，运行期间不得在界面中切换席位类型
