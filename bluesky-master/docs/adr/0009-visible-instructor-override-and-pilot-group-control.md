# 教员越权对模拟飞行员可见并扩展模拟飞行员组控权限

教员仍可绕过航空器当前常规控制模式直接执行越权指令，且不因越权改变智能机长或模拟飞行员的常规控制模式；但该越权不再隐式。模拟飞行员工作台必须展示教员来源、指令内容、执行状态和审计记录，并明确标识由教员操作造成的航空器状态变化。本决策取代 ADR-0004 中“教员介入对模拟飞行员不可见”的部分，保留其中整机常规控制互斥、越权不持续锁定以及控制模式切换规则。

当前仅暂缓本轮关于智能机长未决细节的继续讨论，智能机长控制模式、模拟飞行员双向切换和教员越权规则不因此改变。

模拟飞行员除操作已分配航空器外，还可以对当前所在训练组执行开始和暂停，可以修改全组天气并执行全组故障注入。教员可以执行开始、暂停和结束。暂停后再次点击开始即继续，结束时停止训练并保存已有记录；本期不区分正常结束和强制终止。这些操作必须限定在当前训练组并记录终端、参数、系统时间、仿真时间和结果。

## 后果

- 教员越权事件不再对模拟飞行员做来源过滤，工作台和审计查询采用一致的可见数据
- 智能机长对教员越权完全不可见；智能机长事件流必须过滤来源、内容、标识、审计数据和因果关联，只保留其自身语音交互所需信息
- 开始和暂停同时开放给教员与当前组模拟飞行员，结束只开放给教员；本期不展开极端并发控制和复杂结束收尾设计
- 模拟飞行员仍不能操作其他训练组，也不能绕过指令网关直接修改 BlueSky
