# 机长操作手册——文本指令全量指南

> 适用范围：模拟飞行员工作台第二版（训练平台 + BlueSky Adapter，1.0 迁移桥模式）。
> 本手册中的全部指令均已经业务验收端到端验证（AT-01~AT-05 场景验收 + 逐指令
> 业务用例验收 31/31 PASS）；示例中的导航点均为固定参考快照中的真实数据
> （ZGGG 白云机场、GG512、CEN、P47、ZBAA）。

---

## 1. 指令体系总览

### 1.1 控制通道

每条指令作用于一个或多个**控制通道**，不同通道互不冲突，同通道遵循"后到替换先到"（REPLACE）：

| 通道 | 含义 | 典型指令 |
|---|---|---|
| LATERAL | 水平引导 | HDG、LEFT、RIGHT、DCT、RTE、HOLD、ORBIT、VOR、OFFSET、RESUME、SIDSTAR |
| VERTICAL | 垂直引导 | ALT、VS、P_LEVEL |
| SPEED | 速度 | SPD、MACH、P_TIME（时间约束含速度语义） |
| SPECIAL | 复合/特殊 | TAKEOFF（LATERAL+VERTICAL+SPEED）、ILS（LATERAL+VERTICAL）、MISSED |

### 1.2 提交方式

在模拟飞行员终端页面底部指令框输入**纯文本指令**（回车提交）：

- 必须使用纯文本（不携带 `type` 字段的提交方式）；平台解析器负责语法解析与参数校验。
- 受理成功返回 202，指令进入 `DISPATCHING → EXECUTING → COMPLETED / FAILED / REPLACED / CANCELLED` 生命周期。
- 同通道存在执行中指令时，新指令以 REPLACE 调度生效，旧指令转为 `REPLACED`。

### 1.3 收敛判据（平台侧自动判定）

平台按状态帧持续评估每条 EXECUTING 指令，判定三要素：

1. **目标容差**：按指令类型不同（见各节"收敛判据"）。
2. **稳定窗**：数值收敛类（ALT/VS/SPD/MACH/TAKEOFF）需持续满足容差 10 秒；其余类型 3 秒。
3. **最大执行预算**：按**仿真时间**计（训练暂停时预算自然冻结）。超限指令转入 `FAILED`（TARGET_NOT_REACHED）。

### 1.4 报告

- **命令报告**（command_report）：每条指令到达终态时恰好生成一条，含终态与原因。
- **飞行报告**（flight_report）：TAKEOFF（离地）、LANDED（落地）、MISSED_APPROACH（复飞）等飞行事件，按事件到达时间写入，与指令终态解耦——例如 LANDED 事件发生在 ILS 指令收敛**之后**（飞机还需飞完最后一段五边）。

## 2. 起飞与离场

### 2.1 TAKEOFF——起飞（复合指令）

**语法**：`TAKEOFF <跑道> LEVEL <目标高度ft>`

**示例**（AT-01 验证）：

```
TAKEOFF 02L LEVEL 9000
```

**行为**：航空器按 02L 跑道方向爬升至 9000ft，爬升速度 250kt，LNAV 自动接回计划航路。受理后展开为父项 + VERTICAL/SPEED/LATERAL 三个子项，子项不单独派发，引擎回执统一携带父项 commandId；三个子项全部完成后父项聚合为 COMPLETED。

**收敛判据**：

| 子项 | 判据 |
|---|---|
| VERTICAL | 实际高度进入目标高度 ±300ft |
| SPEED | 实际速度进入 250kt ±5kt |
| LATERAL | 离地即完成（垂直速度 > 100fpm） |

**事件**：离地时产生 `TAKEOFF` 飞行报告。
**预算**：600 仿真秒。

### 2.2 SIDSTAR——离场/进场程序

**语法**：`SIDSTAR <程序代号>`

**示例**（AT-01 验证）：

```
SIDSTAR ZGGG01A
```

**行为**：激活指定程序，LNAV 按程序航路引导。
**收敛判据**：引擎 routeChange 回执 + 3 秒稳定窗。
**预算**：30 仿真秒（程序族）。

## 3. 水平引导

### 3.1 HDG——航向

**语法**：`HDG <三位磁航向>`

**示例**（AT-01 验证）：

```
HDG 090
```

**行为**：转向磁航向 090 并保持。
**收敛判据**：实际航向进入 090 ±2°，稳定 3 秒。
**预算**：180 仿真秒。

### 3.2 LEFT / RIGHT——相对转弯与绝对转向

**语法**：`LEFT|RIGHT <度数>`——1~99 两位数为相对转弯量；三位数为绝对磁航向

**示例**（逐指令验收验证）：

```
LEFT 30          （从当前航向左转 30°）
RIGHT 99         （右转 99°——最大相对转角）
LEFT 090         （左转至绝对磁航向 090）
RIGHT 360        （等同于 RIGHT 000，归一化）
```

**行为**：相对模式的基准是**引擎执行瞬间**的航向，目标航向随回执（headingExecuted）上报，平台按回执目标判定收敛，不受状态帧时延影响。执行时自动断开 LNAV。
**收敛判据**：实际航向进入目标 ±2°，稳定 3 秒。
**预算**：180 仿真秒。
**注意**：`LEFT 0` / `RIGHT 0`（相对零度）为无效指令被拒绝；四位数字（如 `0090`）同样拒绝。

### 3.2 DCT——直飞

**语法**：`DCT <航路点>`

**示例**（AT-01 验证）：

```
DCT GG512
```

**行为**：直飞指定航路点（须在当前航路中）。飞越该点后判定通过。
**收敛判据**：directTo 回执 + passed（飞越）判定，稳定 3 秒。
**预算**：到目标点预计时间 ×2 + 120 秒，上限 3600 秒（距离感知，目标很远时预算自动放宽）。

### 3.3 RTE——航路替换

**语法**：`RTE <航路点...>`（末点必须是落地机场）

**示例**（AT-01 验证）：

```
RTE P47 ZBAA
```

**行为**：以 FULL_UNFLOWN 模式替换未飞航路（已飞前缀保留）；同时写入新的飞行计划版本（只增版本、旧版本只读）。航路中包含 GG512 时也可从中间点接起：

```
RTE GG512 P47 ZBAA        （AT-04 验证）
```

**收敛判据**：routeChange 回执 + 3 秒稳定窗。
**预算**：30 仿真秒（航路族）。

### 3.4 RESUME——接回计划航路

**语法**：`RESUME <接回点>`

**示例**（AT-04 验证）：

```
RESUME GG512
```

**行为**：直飞接回点并恢复按当前计划航路飞行。
**收敛判据**：directTo 回执 + passed，稳定 3 秒。
**预算**：同 DCT（ETA×2+120，上限 3600）。

### 3.5 OFFSET——平行偏置

**语法**：`OFFSET <L|R> <偏置距离>NM`

**示例**（AT-04 验证）：

```
OFFSET R 5NM
```

**行为**：在航路右侧建立 5NM 平行偏置。
**收敛判据**：偏置应用回执，稳定 3 秒。
**预算**：30 仿真秒（动态公式同 DCT）。

### 3.6 VOR——伏尔台径向建立

**语法**：`VOR <台站> <IN|OUT> <径向>`

**示例**（AT-04 验证）：

```
VOR CEN IN 090
```

**行为**：飞至 CEN 电台 090 径向（径向定义 = 电台指向航空器的方位，即电台方位 +180°）并向台建立。
**收敛判据**：径向误差 ≤ 3° 且距台 ≤ 30NM 时判定建立，稳定 3 秒。
**预算**：ETA×2+120，上限 3600 秒。

### 3.7 HOLD——等待盘旋

**语法**：`HOLD <定位点> <L|R> <入航磁航向> <腿长秒>`

**示例**（AT-01、AT-05 验证）：

```
HOLD GG512 R 090 60
```

**行为**：在 GG512 建立右转等待程序，入航航向 090，每边 60 秒。执行状态机为 DIRECTING（转向定位点）→ OUTBOUND（出航边）→ INBOUND（入航边，此时判定"已建立"并回执）。定位点在当前航路中时优先 LNAV 直飞；否则方位转向引导，捕获门限按转弯半径自适应（≥1.5NM，约 2.5 倍转弯半径），保证从任意方向签发都能入位。

**收敛判据**：holdEstablished 回执，稳定 3 秒。
**预算**：保底 900 秒；签发时距定位点较远则按距离延长（ETA×2 + 240 + 2×腿长），上限 3600 秒。
**注意**：HOLD 收敛后航空器持续按等待程序飞行，直到被后续水平指令（如 ILS/RTE/DCT）替代。

### 3.8 ORBIT——原地盘旋（不定指令）

**语法**：`ORBIT <L|R> [半径NM]`，退出用 `ORBIT EXIT`

**示例**（AT-05 验证）：

```
ORBIT L 5NM
```

**行为**：以当前速度/指定半径连续标准转弯盘旋（转弯率 = 速度/(60×半径)）。
**收敛判据**：**无**——ORBIT 为不定执行指令，保持 EXECUTING 直至被同通道新指令替代或人工取消，这是设计语义。
**注意**：训练暂停期间盘旋随仿真一并冻结。

## 4. 垂直与速度

### 4.1 ALT——高度

**语法**：`ALT <高度ft>`

**示例**（AT-01 验证）：

```
ALT 10000
```

**行为**：爬升/下降至指定高度层。
**收敛判据**：实际高度 ±100ft，稳定 10 秒。
**预算**：max(300, 爬升预测×2+60)，上限 3600 秒（名义爬升率 1500fpm 估算）。

### 4.2 VS——垂直速度

**语法**：`VS <±数值><FPM|MPS>`（非零值必须带符号）；厂商别名 `CR`（爬升）/`DR`（下降）

**示例**（逐指令验收验证）：

```
VS +1000FPM      （以 1000 英尺/分钟爬升）
VS -5MPS         （以 5 米/秒下降，约合 984fpm）
VS 0             （恢复平飞）
CR 1200          （等价于 VS +1200FPM）
DR 800           （等价于 VS -800FPM）
```

**行为**：按给定升降率爬升/下降，无目标高度（引擎按升降方向自动配对 3000ft 缓冲高度层实现恒定升降率）。
**收敛判据**：实际垂直速度进入目标 ±150fpm，稳定 10 秒。
**预算**：300 仿真秒。
**注意**：`VS 1000`（非零无符号）与 `VS +6001FPM`（超性能包线）均被拒绝。

### 4.3 SPD——速度

**语法**：`SPD <表速kt>`

**示例**（AT-01 验证）：

```
SPD 250
```

**收敛判据**：实际速度 ±5kt，稳定 10 秒。
**预算**：600 仿真秒。

### 4.4 MACH——马赫数

**语法**：`MACH <0.10~0.99>`

**示例**（逐指令验收验证）：

```
MACH 0.78
```

**行为**：以马赫数持速（在巡航高度层使用）。
**收敛判据**：实际马赫数 ±0.01，稳定 10 秒。
**预算**：600 仿真秒。
**注意**：解析包线为 0.10~0.99——超出即 422 拒绝（`MACH 0.09` / `MACH 1.0`）；但 0.10/0.99 等边界值虽被受理（202），超出运输类性能包线，物理上不可达，业务预期为预算耗尽 FAILED。

### 4.5 P_LEVEL——航段高度约束

**语法**：`P_LEVEL <航路点> <高度ft>`

**示例**（AT-04 验证）：

```
P_LEVEL P47 12000
```

**行为**：对当前计划版本中 P47 所在航段施加高度约束（12000ft）。冲突键按航段独立（同一航路点在不同航段互不冲突）。
**收敛判据**：planConstraintApplied 回执，稳定 3 秒。
**预算**：30 仿真秒（约束族）。

### 4.6 P_TIME——航段时间约束

**语法**：`P_TIME <航路点> T+<秒>`

**示例**（AT-04 验证）：

```
P_TIME P47 T+300
```

**行为**：要求在计划时间 +300 秒通过 P47 航段。
**收敛判据/预算**：同 P_LEVEL。

## 5. 进近与复飞

### 5.1 ILS——仪表进近（复合指令）

**语法**：`ILS <机场> <跑道> <L|R> <截获磁航向>`

**示例**（AT-01、AT-02 验证）：

```
ILS ZGGG 02L L 350
```

**行为**：对 ZGGG 02L 跑道建立仪表进近。引擎侧自动在五边反向 12NM 处生成远端定位点（ILSFAF）并将机场加入航路，采用**两段锁存引导**：先直飞 FAF 重建几何（无论航空器当前在机场哪一侧、离多远），距 FAF ≤ 2.5NM 时单向提交转入五边，直飞机场点直至落地——该锁存消除门限两侧目标翻转，保证从等待/盘旋等任意态势签发均能稳定入位。受理后展开为父项 + LATERAL/VERTICAL 子项。

**收敛判据**：

| 子项 | 判据 |
|---|---|
| LATERAL | 对准中心线（方位差 ≤10°）且处于进近侧（沿五边轴投影 ≥3NM）、距机场 ≤20NM |
| VERTICAL | LATERAL 建立后距机场 ≤12NM，转五边下降（50ft / 160kt） |

**事件**：距机场 ≤0.5NM 时产生 `LANDED` 飞行报告（落地事件晚于指令收敛属正常——收敛在截获建立时即判定）。
**预算**：1800 仿真秒。

### 5.2 MISSED——复飞

**语法**：`MISSED`

**示例**（AT-02 验证）：

```
MISSED
```

**行为**：立即终止当前 ILS 进近，爬升 2500ft，LNAV 接回计划航路。
**收敛判据**：较起始高度爬升 ≥500ft 且垂直速度 >0（爬升建立）+ 水平引导接通。
**事件**：产生 `MISSED_APPROACH` 飞行报告。
**预算**：900 仿真秒。

## 6. 生命周期操作

### 6.1 CANCEL——取消指令

对处于 `BLOCKED`（阻塞排队）或 `EXECUTING`（执行中）的指令可发起取消，成功后指令转入 `CANCELLED` 并生成命令报告（AT-03 验证：移交后目标席取消既有队列全链）。`DISPATCHING`（下发确认中）与终态（COMPLETED/FAILED/REPLACED 等）不可取消；`RECEIVED`/`VALIDATED` 为受理内瞬态，对使用者不可见。

**输入框文本形式**（模拟飞行员工作台）：选中航空器后直接输入

```
CANCEL
取消
```

（大小写不敏感，前后空白忽略）——取消**该机最新一条活动指令**，不创建新指令；受理成功返回被取消的指令行（状态原地刷新为 `CANCELLED`）。若该机当前没有活动指令，返回 409「该航空器当前没有可取消的活动指令」；若最新指令恰在下发确认中，返回 409「最新指令正在下发确认中，请稍候重试取消」，稍候重试即可。

**示例**：

```
HOLD GG512 R 090 60     ← 先签发一条长预算指令（EXECUTING）
CANCEL                   ← 输入框输入 CANCEL，队列中该指令立即转 CANCELLED
```

### 6.1.1 删除航空器

航空器列表行的「×」按钮删除该航空器：服务端在单请求内完成 v2 删除 Saga（一次性确认 token 服务端签发并原子消费 → 删除请求 → 适配器实体删除 → 确认收尾），成功后该机自列表移除、责任分配结束、活动指令全部取消。仅当前责任席可删除；训练组须处于 RUNNING/PAUSED。

### 6.2 训练暂停/恢复对指令的影响

- 预算按**仿真时间**推进：训练暂停（pause）期间所有 EXECUTING 指令的预算冻结，恢复（resume）后继续（AT-05 验证了暂停冻结不变式）。
- 引擎倍率（如 8x）只影响仿真推进速度，不影响预算的仿真秒数额。
